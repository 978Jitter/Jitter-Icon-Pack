# Jitter-Icon-Pack
Jitter-Forge: A crisp monochrome &amp; silver-white vector SVG icon suite engineered to pair with Jitter-Shadow on Linux XFCE &amp; ARM64 cyberdecks. Features sharp geometric cyber-glyphs, custom folder &amp; places badges, waveform device icons, panel dock launchers, and status tray symbolics. Built for Kali ARM64, Debian Jitter OS, Fedora &amp; Pop!_OS.

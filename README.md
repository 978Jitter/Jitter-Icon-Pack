# // JITTER ICONS (`Jitter-Forge`)

A custom monochrome and silver-white vector icon pack engineered to pair seamlessly with the matte-black and crimson (`#E11D2E`) **Jitter-Shadow** desktop theme on Linux XFCE and portable ARM64 cyberdecks.

### 🎨 Design Language
* **High-Contrast Monochrome:** Crisp silver-white (`#CFCFD3` / `#FFFFFF`) line-art and geometric glyphs designed to pop against `#0D090A` and `#181012` dark surfaces without visual clutter[cite: 9, 10].
* **Cyberdeck & RF Motifs:** Custom pulse-waveform icons for removable drives and hardware tools, hexagonal badges, terminal glyphs, and clean angular folders[cite: 9, 10].

### 📦 Coverage
* **Places & File Manager (Thunar):** Custom folder glyphs for `Home`, `Desktop`, `Recent`, `Trash`, `Documents`, `Music`, `Pictures`, `Videos`, `Downloads`, `File System`, and `Browse Network`[cite: 9, 10].
* **XFCE Settings & System Tools:** Uniform geometric icons across `Appearance`, `Panel`, `Window Manager`, `Display`, `Bluetooth`, `Power Manager`, `Keyboard`, and `Session & Startup`[cite: 10].
* **Panel & System Tray Symbolics:** Crisp dock launcher icons, crimson-accented application menu emblem, and monochrome tray status indicators (volume, battery, network, power)[cite: 9].
